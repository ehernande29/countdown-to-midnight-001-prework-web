# Figure Sketch App - Quick Start Guide

## Installation (5 minutes)

### Prerequisites
- **Node.js** v16 or higher ([Download here](https://nodejs.org/))
- **npm** (comes with Node.js)

### Setup Steps

1. **Open terminal in this directory**

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and go to `http://localhost:3000`

That's it! 🎉 The app will open automatically.

---

## How to Use (Quick Overview)

### The Interface
- **Left Panel**: Pose presets, undo/redo, figure management
- **Center**: Main canvas for drawing and interaction
- **Right Panel**: Display settings and export options

### Basic Workflow

1. **Pick a Pose**: Click any preset button (Standing, Walking, Running, etc.)
2. **Tweak It**: Drag body parts to adjust the pose
3. **Customize**: Choose background, add guides, adjust style
4. **Export**: Download as JPG or PNG

### Controls
- **Rotate Limbs**: Click and drag any body part
- **Move Figure**: Click and drag the background
- **Scale**: Use slider in right panel
- **Add More**: Click "+ Add Figure" for multiple figures
